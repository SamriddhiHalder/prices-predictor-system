# 🏠 prices-predictor-system

A machine learning project that predicts housing prices using structured data from the Ames Housing dataset. This project implements a full ML pipeline including data analysis, preprocessing, model training, deployment simulation, and sample predictions.

---

## 📌 Features

- End-to-end ML pipeline using Python
- Clean architecture with modular components
- Exploratory Data Analysis (EDA) using Jupyter Notebook
- Implements software design patterns (Factory, Strategy, Template)
- Deployment-ready prediction script
- Well-organized folder structure

---
